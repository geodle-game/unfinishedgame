# VELOCITY: BREAKPOINT

A 3D first-person, skill-based speedrunning roguelite built with **Three.js** and **vanilla JS modules**.
No build step, no backend, no API keys — deploys directly to **GitHub Pages** or **Netlify**.

---

## Running locally

Because the project uses ES modules, you must serve it over HTTP (not `file://`).

```bash
# Python
python -m http.server 8080

# or Node
npx serve .
